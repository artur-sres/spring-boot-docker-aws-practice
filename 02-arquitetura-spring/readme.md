# Arquitetura Spring

Pequenos scripts usados somente para entender a estruturação de aplicações Spring Boot e compreender os principais conceitos relacionados à arquitetura, componentes e injeção de dependências.
## Conteúdos

- Funcionamento do Spring Boot
- Arquitetura do Spring e seus componentes
- Classe `Application`
- Injeção de dependências
- Beans e `@Bean`
- Annotations e Qualifiers
- Estrutura de projetos MVC
- Entidades e camadas da aplicação
- Components e escopos de Beans
- Lazy Beans
- Configurações externas com `application.properties`
- `@Value`
- Configuration Properties
