# Library API

API REST desenvolvida com Spring Boot para praticar acesso a dados utilizando Spring Data JPA e PostgreSQL com o objetivo de praticar o acesso e a manipulação de dados em aplicações Spring Boot utilizando Spring Data JPA e PostgreSQL.

## Tecnologias

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Docker
- Maven
- Lombok

## Conteúdos

- Configuração do PostgreSQL com Docker
- Docker Network
- Modelagem de banco de dados
- Configuração da conexão com o banco
- DataSource e Pool de conexões
- Mapeamento de entidades com JPA
- Repositories
- Operações de persistência
- Relacionamentos entre entidades
- Cascade
- Lazy e Eager Loading
- One-to-Many
- Query Methods
- Consultas com JPQL e `@Query`
- Named e Positional Parameters
- Operações de `delete` e `update`
